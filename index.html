1浏览量集中 200-500 区间（46.4%）爆款（>2000）几乎不存在
216-25 字标题平均浏览量最高（521.3）标题分组图

8艺术创作类情感最高（0.82）新闻通知最低（0.55）

10.2 运营策略建议

维度建议预期效果
标题控制在 16-25 字，嵌入核心关键词浏览 +10%~15%
内容通知类新闻加入具体人物/场景描写情感得分 +0.1~0.2
渠道加强微博分发，"艺术创作"同步发小红书平台覆盖翻倍
节奏暑期不减量配合招生季加大发布受众增长可持续
受众区分"面向师生"与"面向社会"两类策略触达精准度提升
情感获奖/展演类加大渲染；通知类保持中性传播力评分 +10

10.3 数据驱动决策树

标题字数 > 25?
  ├─ 是 → 缩短至 16-25 字
  └─ 否 → 浏览量有保障

情感得分 < 0.6?
  ├─ 是 → 加入人物故事/情绪表达
  └─ 否 → 保持现有风格

浏览量 > 1000?
  ├─ 是 → 分析成功因素：话题性/视觉/热点
  └─ 否 → 优化标题/内容/渠道

11.3 数据局限性

  1. 来源偏倚：新闻网 92.9%，结论推广受限
  2. 情感天花板：正面情感得分均值 0.994，区分度不足
  3. 主题分类：基于关键词匹配，未覆盖新兴主题
  4. LLM 样本：仅 30 条（4.4%），统计稳定性有限
